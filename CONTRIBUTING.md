# Contributing to WFX

I'm surprised you actually decided to contribute to this 'whatever' of a project. Thank you 'user'.

Fork the repo, clone your fork on `dev`, and read
[Development Setup](https://altered-commits.github.io/WFX/dev_reference/dev_setup/) for
everything else: building, coding conventions, formatting, static analysis, testing, docs, and
what to do before opening a PR.

`main` and `dev` are protected. PR against `dev`, never `main`.

So yeah, have fun contributing, ig.
